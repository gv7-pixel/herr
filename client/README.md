# Herr — Client (Frontend)

React + Vite frontend for Neha's personalized romantic birthday surprise website.

## Scripts

- `npm run dev` — Starts the Vite development server on port 5173 with proxy to backend API (`http://localhost:5000`).
- `npm run build` — Builds the optimized production bundle to `dist/`.
- `npm run preview` — Locally preview the production build.

## Structure

- `public/assets/` — Dedicated folders for photos, featured beach photograph, audio, stamps, and textures.
- `src/sections/` — Sequenced experience components (Envelope, Countdown, Memories, Featured Photo, Letters, Our Song, Final Envelope).
- `src/hooks/` — Audio management and custom hooks.
- `src/components/` — Reusable UI components.
- `src/styles/` — Mobile-first CSS foundation.
